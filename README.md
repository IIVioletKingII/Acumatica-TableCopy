# Acumatica-TableCopy
A quick Chrome extension for copying tables from Acumatica.

## Install (developer mode)
1. Open `chrome://extensions` and turn on **Developer mode** (top right).
2. Click **Load unpacked** and select this folder.
3. Pin the extension from the puzzle-piece menu.

## Use
1. On an Acumatica screen, click the extension icon (or press **Alt+Shift+C**). The badge shows **ON**.
2. Hover a grid to highlight it, then click it to copy its rows as tab-separated text.
3. Paste into Excel or Sheets. Press **Esc** or click the icon again to cancel.

## After editing the code
Click the reload icon on the extension's card in `chrome://extensions`, then refresh the Acumatica tab.
